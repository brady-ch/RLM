Implication for the UI

Nodes should be typed modules, not just prompts. Each node needs visible artifact ports, a node type, a model/runtime selector, prompt or code configuration, batching controls, and validation state.

Recursive planning role

Plan mode should generate this graph from a high-level request, but the user can then open any high-complexity node and plan its internal subgraph with the same budget rules.
