Create scripts/packaging/deb-smoke-lib.mjs exporting pure functions used by the smoke entry script (per D-02, D-03, D-04):

1. findDebArtifact(root) — resolve repo root, glob src-tauri/target/release/bundle/deb/*.deb, pick newest mtime; throw/return null with message if none.

2. shouldSkipDebSmoke(env, platform) — return { skip: true, reason } when env.RLM_SKIP_DEB_SMOKE === "1"; on linux when pkg-config glib-2.0 fails (spawnSync pkg-config --exists glib-2.0); on non-linux return skip with "deb smoke is Linux-only". Skip paths must NOT throw.

3. installDeb(debPath) — spawnSync sudo dpkg -i debPath; on failure run sudo apt-get install -f -y then retry once; capture stderr.

4. findInstalledBinaries() — after install, spawnSync dpkg -L with package name inferred from deb filename OR scan dpkg -L for paths ending in /rlm or matching Tauri desktop slug under /usr/bin; return { cliPath, desktopPath } (desktopPath may be null).

5. uninstallDeb(debPath) — derive package name from deb basename (dpkg-deb -f debPath Package) and run sudo dpkg -r when installed.

Use node:fs, node:child_process spawnSync, node:path only — no new npm dependencies.
  </action>

deb-smoke-lib.mjs exports findDebArtifact, shouldSkipDebSmoke, installDeb, findInstalledBinaries, uninstallDeb; shouldSkipDebSmoke returns skip object when RLM_SKIP_DEB_SMOKE=1 without executing dpkg; findDebArtifact documents expected Tauri bundle path in file header comment.
  </acceptance_criteria>

Create scripts/packaging/smoke-deb.mjs as the executable entry (shebang + node):

1. Call shouldSkipDebSmoke — if skip, console.error one line with reason + pointer to docs/DESKTOP.md, exit 0 (per D-03).

2. Require deb path from argv[2] or findDebArtifact — if missing and no artifact, exit 1 with "run npm run tauri:build first".

3. installDeb in try/finally; finally always attempts uninstallDeb.

4. CLI smoke: spawnSync discovered cliPath with ["--help"]; status must be 0 (per D-04).

5. Desktop smoke when desktopPath exists: spawnSync xvfb-run with ["-a", "timeout", "15s", desktopPath] (or timeout wrapping desktop binary directly if xvfb-run missing — then exit 1 with install xvfb message). Treat timeout exit 124 as success if stderr lacks "Failed to initialize GTK" / "Cannot open display".

6. On success console.error "Deb smoke passed for {debPath}".

Do not invoke tauri:build inside this script — caller supplies built deb (CI or local).
  </action>
