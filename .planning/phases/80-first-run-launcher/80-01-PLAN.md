# Plan 80-01: First-Run Launcher

## Objective

Add guided composer + session picker launcher overlay for pristine first-run graphs; graph workspace primary after dismissal; Advanced via TopBar only.

## Tasks

### T1 — FirstRunLauncher component

Create `ui/src/app/FirstRunLauncher.tsx` and `ui/src/shared/session-utils.ts`:

- `isPristineFirstRunGraph(snapshot)` — single root-composer, no edges
- Guided composer: prompt textarea, Continue to graph (edit prompt), optional Plan children
- Session picker: list from `/api/saved-sessions`, Open + Start fresh
- `data-testid="first-run-launcher"`

**Verify:** `npm run build:ui`

### T2 — AppShell integration

Wire launcher in `AppShell.tsx`:

- Show overlay when pristine graph and not dismissed
- Dismiss on continue, start fresh, or open saved session
- Workflow view (TopBar + canvas + RunPanel) remains primary after dismiss
- Advanced only via TopBar

**Verify:** `npm run build:ui`

### T3 — Launcher contract test

Create `tests/ui/first-run-launcher.test.ts`:

- `FirstRunLauncher.tsx` exists with guided composer + session list patterns
- `AppShell.tsx` integrates launcher + pristine check
- Launcher must not import from `advanced/`
- TopBar Advanced button present in workflow branch

**Verify:** `npm test` (first-run-launcher subset)

### T4 — Styles + phase verification

Add launcher styles to `ui/src/styles.css`. Write `80-VERIFICATION.md` with `status: passed`.

**Verify:** `npm run build:ui` && `npm test`

## Success Criteria

1. Fresh user sees guided composer with prompt before graph authoring
2. User can open saved session or start fresh from launcher
3. After launcher, graph workspace is primary; Advanced secondary via TopBar
4. Refresh with graph progress skips launcher
