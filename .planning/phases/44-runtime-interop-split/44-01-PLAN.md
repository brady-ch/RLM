# Plan 44-01: Runtime & Interop Split

## Objective

Move composition and MCP/skill interop wiring to `src/runtime/`; bootstrap becomes thin re-export facade; init order preserved and tested.

## Tasks

1. **Extract composition modules** — Move `extension-host`, `runtime-composition`, and `buildRuntimeContext` body to `src/runtime/composition/`; bootstrap re-exports only.
2. **Extract interop modules** — Move `interop-runtime` and `mcp-skill-runtime` to `src/runtime/interop/`; remove from application.

4. **Init-order unit test** — Verify bootstrap sequence (plugins → interop → tools resolver → agent registry → models) without full CLI/control-server.
5. **Regression gate** — `npm run check` green.
