# Phase 50 Plan 01: Remote Fetch

## Objective

Remote plugin install from HTTPS archives or git URLs with fetch-to-local semantics, security defenses, and doctor --fix repair.

## Tasks

### Task 1: Remote fetch transport (type=auto)

Add `src/plugins/remote-fetch/` with HTTPS archive download, safe tar extraction (zip-slip + max size), and optional git spawn fetch.

### Task 2: Registry installRemote and doctorFix (type=auto)

Extend `PluginRegistryService` with `installRemote`, `install` routing, and `doctor({ fix: true })` quarantine/prune.

### Task 3: CLI and control-server wiring (type=auto)

URL detection in `rlm plugin install`, `--fix` on doctor, `--yes` for install confirm; control-server remote install + doctor fix routes.

### Task 4: Tests (type=auto)

Add remote-fetch unit tests and registry integration tests for installRemote, zip-slip rejection, and doctor --fix.
