**Three parallel registries** (per D-05):
```typescript
tools: {
  register(tool: ToolPort): void;  // throws if tool.name already registered
  get(name: string): ToolPort | undefined;
  all(): ToolPort[];
}
skillLoaders: {
  register(loader: SkillLoaderPort): void;
  get(name: string): SkillLoaderPort | undefined;
}
modelHosts: {
  register(adapter: LanguageModelPort): void;
  get(name: string): LanguageModelPort | undefined;
}
```
Each registry is backed by a `Map`. `register()` throws `Error` if the name already exists (per pitfall 4 / ERRO-03 — no silent overwrite).

**`loadBuiltins(entries: Array<{ path: string; register: (host: ExtensionHost) => void }>): void`**
Accepts already-imported first-party module references (no `import()` needed). Calls `entry.register(this)` for each. No allowlist check — caller (index.ts) is the composition root and takes responsibility.

**`async loadExternal(entries: ExtensionRegistryEntry[], opts: { configFilePath: string; allowlistPath?: string; interactive?: boolean }): Promise<void>`**
For each entry:
1. Resolve absolute path: `isAbsolute(entry.path) ? entry.path : resolve(dirname(opts.configFilePath), entry.path)` — config-dir-anchored (per D-02 and A1 from research).
2. Convert to file URL: `pathToFileURL(absPath).href` — required on Windows (per risk 1 in RESEARCH.md).
3. Check allowlist: compute `sha256` of absPath via `createHash("sha256").update(absPath).digest("hex")`. Read `opts.allowlistPath ?? join(dirname(opts.configFilePath), ".rlm-allowlist.json")` as JSON. Use `Object.hasOwn(list, key)` to check.
4. If not approved and `opts.interactive !== false`: prompt via `readline/promises` `rl.question()` "Allow extension at {absPath}? [y/N] ". If user answers "y"/"Y"/"yes", persist approval to allowlist JSON (create/merge); otherwise throw `Error("Extension not approved: {absPath}")`.
5. If not approved and `opts.interactive === false`: throw `Error("Extension not approved and interactive=false: {absPath}")`.
6. `const mod = await import(fileUrl)` — wrapped in try/catch to throw `Error("Failed to load extension at {path}: {cause}")`.
7. Validate `typeof mod.register === "function"`; throw `Error('Extension at {path} does not export a "register" function.')` otherwise.
8. Call `mod.register(this)`.

**`async preApprove(absPath: string, allowlistPath: string): Promise<void>`**
Test-only helper: writes the allowlist entry directly without prompting. Used in integration tests.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| YAML config → ExtensionHost | User-controlled `extensions.load[].path` values enter the loader; path traversal possible |
| allowlist file → ExtensionHost | JSON read from disk; malformed file must not crash the loader silently |
| extension module → host registries | Arbitrary third-party code runs after `import()`; collision/overwrite must not be silent |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-01 | Elevation of Privilege | `ExtensionHost.loadExternal()` — `import()` call | mitigate | Allowlist check (sha256 key lookup) completes and returns `true` before `import()` is called; loading skipped/throws if not approved |
| T-06-02 | Elevation of Privilege | Extension module top-level side effects | mitigate | Covered by T-06-01: `import()` is never called until approval confirmed |
| T-06-03 | Tampering | YAML `path:` value (path traversal) | mitigate | `path.resolve(configDir, entry.path)` normalizes `../` traversal; resolved absolute path is used as the trust identity and logged to stderr before import |
| T-06-04 | Tampering | Tool registry `register()` — name collision | mitigate | Registry throws `Error` on duplicate name (no silent overwrite); consistent with ERRO-03 |
| T-06-05 | Denial of Service | Malformed `.rlm-allowlist.json` | accept | `JSON.parse` failure is caught; treated as empty allowlist (not yet approved), triggering prompt or throw; no crash |
</threat_model>
