# Phase 58 Plan 01: Built-in Plugins + MCP + Registry

## Goal

Port builtin tools, PluginRegistryService, control-server plugin routes, and runtime init order to Rust with v1.7 parity.

## Tasks

### 1. ExtensionHost + builtin tools (type=auto)
- `plugins/extension_host.rs` with tool registration
- Builtin tools: shell, write_file, web_search, web_fetch with v1.7 guard semantics

### 2. PluginRegistryService (type=auto)
- Manifest validation, catalog paths, list/install/enable/disable/uninstall/doctor/inspect/validate
- Remote fetch with zip-slip, size limits, confirm gate

### 3. Control server routes (type=auto)
- Wire `/api/plugins/*` matching TS handlers
- RouterState holds `PluginRegistryService` when project config present

### 4. Runtime init + tool rounds (type=auto)
- Init order: plugins → interop (stub) → tools resolver → agent registry → models
- Wire tools into GraphExecutor / RecursiveLanguageModel

### 5. Tests + verification (type=auto)
- Unit tests for guards, registry, init order, plugin routes
- `cargo test -p rlm-core` and `npm run check:rust` green
