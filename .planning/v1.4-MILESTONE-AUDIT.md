## Critical Gaps (Recommended Closure)

1. **Wire save to live memory** — Serialize scopes, episodic, preferences, and vector manifest from store/index into session bundle (SESS-01, RETR-05, SURF-03).
2. **Persist and rebind runId on reopen** — Store runId in snapshot; rebind MemoryResolver to saved session memory (SESS-01, MEM-04, SURF-02).
3. **Align CLI with API 409 gate** — Block `--open-session` continuation when verification !== complete (SESS-04, SURF-01).
4. **Async vector indexing** — Queue index updates after writes; avoid sync rebuild in buildPacket (RETR-02).
