- `!state.session.is_confirmed_execution_running()`
- `persistence.get_snapshot()` is Some
- snapshot has `resume_cursor` JSON present (interrupted mid-run, not idle store)
- Optionally include `activeNodeId` from parsed `ResumeCursor.active_node_id` when resumable
</interfaces>
