# Phase 22-01 Plan: Model Library

## Goal

Implement the first usable model library surface for the desktop product milestone.

## Tasks

### Task 1: Model Library Service

Files:
- `src/application/model-library.ts`
- `src/index.ts`

Steps:
1. Add a service with curated model entries, installed model discovery, install jobs, Hugging Face search, and tier assignment.
2. Wire the service into UI mode using the selected runtime host base URL.

### Task 2: Control Server API

Files:
- `src/application/control-server.ts`

Steps:
1. Add `GET /api/model-library`.
2. Add `POST /api/model-library/install`.
3. Add `GET /api/model-library/search?q=...`.
4. Add `POST /api/model-library/select-tier`.

### Task 3: UI Model Library Panel

Files:
- `ui/src/main.tsx`
- `ui/src/styles.css`

Steps:
1. Show curated models with tags, RAM hints, install state, and install action.
2. Show installed models and current tier assignments.
3. Add Hugging Face search with unsupported states and reasons.
4. Allow installed models to be assigned to configured tiers.

### Task 4: Tests and Verification

Files:
- `tests/recursive-language-model.test.ts`

Steps:
1. Add control-server/model-library API coverage with mocked Ollama and Hugging Face responses.
2. Run build, focused tests, UI build, and full test suite.

## Verification Commands

```bash
npm run build
npm run build:ui
node --test dist/tests/recursive-language-model.test.js
npm test
```
