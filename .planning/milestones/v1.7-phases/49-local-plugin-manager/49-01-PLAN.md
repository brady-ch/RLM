# Phase 49 Plan 01: Local Plugin Manager

## Objective

CLI plugin management with shared `PluginRegistryService` backing CLI and control-server.

## Tasks

### Task 1: PluginRegistryService and catalog paths (type=auto)

Add `PluginRegistryService` under `application/plugins/`, user catalog paths under `plugins/paths.ts`, and multi-catalog loading in `PluginLoader` + `buildRuntimeContext`.

### Task 2: CLI plugin commands (type=auto)

Add `rlm plugin list|install|enable|disable|uninstall|doctor|inspect|validate` with `--json` support.

### Task 3: Control-server plugin routes (type=auto)

Add `/api/plugins/*` handlers wired through shared `PluginRegistryService`.

### Task 4: Tests (type=auto)

Add `tests/application/plugins/plugin-registry-service.test.ts` covering list/install/enable/disable/uninstall/doctor/inspect/validate.
