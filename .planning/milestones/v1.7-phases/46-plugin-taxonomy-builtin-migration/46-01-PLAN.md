# Phase 46 Plan 01: Plugin Taxonomy & Builtin Migration

## Objective

Establish first-class plugin packages with manifest validation, unified discovery via PluginLoader, and migrate built-in tools from extensions/adapters to `src/plugins/builtin/`.

## Tasks

### Task 1: Manifest schema and PluginLoader (auto)

Add `src/plugins/` with Zod manifest schema, category taxonomy, PluginLoader (builtins → configured → catalog), and legacy `extensions.load` compat shim.

### Task 2: Builtin migration and bootstrap wiring (auto)

Move tool implementations to `src/plugins/builtin/{shell,files,web}/`, wire `buildRuntimeContext` through PluginLoader, remove `src/extensions/tools/` and `src/adapters/tools/` implementations.

### Task 3: Tests and contributor docs (auto)

Add `tests/plugins/plugin-loader.test.ts`, update AGENTS.md taxonomy, ensure `npm run check` green.

## Success Criteria

1. `rlm.plugin.json` validated with Zod before import
2. Categories: shell, files, web, interop
3. Built-ins in `src/plugins/builtin/` with manifest + register
4. PluginLoader replaces hardcoded loadBuiltins
5. Legacy extensions.load compat shim
6. adapters/ infrastructure only
7. AGENTS.md documents taxonomy
