<threat_model>
## Trust boundaries

| Boundary | Description |
|----------|-------------|
| CI runner → npm install | Supply-chain: lockfile must gate dependency versions |
| Packaging script → filesystem | Writes under `dist/release/` only; must not `rm -rf` home or arbitrary paths |
| Launcher stub → `node` | Invokes system Node; path to `node` should be explicit or PATH with no injection from untrusted cwd |

## STRIDE register

| Threat ID | Category | Component | Disposition | Mitigation plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10-01 | Tampering | CI cache / dependency confusion | mitigate | Use `npm ci` with lockfile in workflow; no `curl \| bash` without checksum |
| T-10-02 | Information disclosure | Artifact upload contains secrets | mitigate | Do not copy `.env` or `*.pem` into `dist/release/`; grep staging paths in script |
| T-10-03 | Elevation | Launcher executes wrong interpreter | mitigate | Document that shim resolves `node` via env `NODE_PATH` optional override only from user env, not repo files |
</threat_model>
