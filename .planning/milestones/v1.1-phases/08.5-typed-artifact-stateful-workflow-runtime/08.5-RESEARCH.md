# Phase 8.5: Typed Artifact + Stateful Workflow Runtime - Research

**Researched:** 2026-05-11  
**Domain:** Typed artifact contracts, stateful run persistence, optimistic concurrency + ACL, audit/replay semantics  
**Confidence:** HIGH

---

## Summary

Phase 8.5 should be delivered in two waves:

1. **Wave 1 (08.5-01):** typed artifact contracts and runtime boundary validation wired into recursive execution, including code-only node lifecycle parity.
2. **Wave 2 (08.5-02):** external run-state store with optimistic concurrency, path-level ACL, append-only mutation audit, and operational replay helpers.

The implementation should preserve existing architectural boundaries:
- Contract and graph semantics in `src/domain/`
- Orchestration and stateful control in `src/application/`
- Store and persistence mechanics in `src/ports/` + `src/adapters/`

---

## Locked Decisions Applied

- Hybrid schema contract: node input/output schemas are authoritative, optional edge-level narrowing is allowed, widening is forbidden.
- Validation is strict-by-default with explicit per-node policy override.
- Run-state store is introduced as a port now, with file-backed adapter in this phase.
- Persist standard scope: run metadata, node status map, artifact refs, mutation log, checkpoint snapshots, resume cursor.
- Concurrency is reject-on-conflict via `version`/`etag` checks.
- Mutation ACL is path-prefix based with per-node capability token checks.
- Code-only nodes share the same lifecycle model as model-backed nodes, with `code_execution` subtype events for observability.
- Audit payload includes actor/path/action/accept-or-reject/reason/timestamp/sequence.
- Replay target is operational replay (decision/checkpoint reconstruction), not deterministic payload replay.

---

## Architecture Split

### Domain contracts and validation
- Extend `src/domain/types.ts` for artifact contract references, boundary validation outcomes, and run-state identifiers.
- Add artifact schema compatibility checks (node source-of-truth + edge narrowing).
- Ensure validation failures are explicit runtime errors with no silent fallback.

### Runtime orchestration integration
- Integrate boundary validation hooks in `src/domain/recursive-language-model.ts`.
- Keep code-only nodes on the same execution lifecycle path and emit `code_execution` subtype markers through existing runtime event patterns.

### Run-state boundary and adapter
- Add run-state store port in `src/ports/` and file adapter in `src/adapters/`.
- Wire orchestration through `src/application/execution-controller.ts` and related runtime modules.
- Add optimistic concurrency + ACL guards to mutation endpoints.

### Audit and replay surface
- Reuse `src/application/runtime-events.ts` identity/fingerprint patterns for mutation event streams.
- Add deterministic sequence allocation for run-state mutations.
- Surface replay-oriented inspection data in control/CLI paths without claiming full deterministic replay.

---

## Risks and Mitigations

1. **Schema drift between nodes and edges**
   - Mitigation: single compatibility function that rejects edge widening and reports exact mismatch path.
2. **State corruption under concurrent writes**
   - Mitigation: mandatory etag/version match with explicit conflict responses and no implicit merge.
3. **ACL bypass via overly broad path grants**
   - Mitigation: deny-by-default prefix checks and capability token scope binding to node/action.
4. **Audit signal gaps for rejected mutations**
   - Mitigation: log both accepted and rejected attempts with reason code and stable sequence.

## Recommendation

Produce two executable plans:
- `08.5-01-PLAN.md`: artifact contract typing, boundary validation, code-only lifecycle/event parity.
- `08.5-02-PLAN.md`: run-state store port+file adapter, concurrency/ACL enforcement, audit log + operational replay + tests.

Keep backward compatibility explicit:
- Existing flows without configured artifact schemas continue to execute with current behavior.
- New strict validation/concurrency/ACL behavior activates only where Phase 8.5 contracts are configured.
