# Phase 26-01 Plan: Structured Memory Store and Resolver

## Goal

Implement canonical structured memory scopes, episodic continuity, authorization/audit behavior, and bounded memory context packets.

## Tasks

### Task 1: Memory Store Port and File Adapter

Files:
- `src/ports/memory-store-port.ts`
- `src/adapters/file-memory-store.ts`

Steps:
1. Define scope documents, lifetimes, patch requests/results, audit records, episodic entries, rolling summaries, and packet metadata.
2. Implement file-backed scope documents with version checks and atomic writes.
3. Implement accepted/rejected audit records for scope patches.
4. Implement append-only episodic entries and deterministic rolling summary.

### Task 2: Memory Resolver

Files:
- `src/application/memory-resolver.ts`

Steps:
1. Resolve authorized scopes from `contextPolicy.memoryScopes`.
2. Build bounded context packets from structured scopes and rolling episodic summaries.
3. Include provenance, truncation, and degraded metadata.
4. Record packet metadata for inspection without storing full prompt dumps.

### Task 3: Runtime Integration

Files:
- `src/domain/types.ts`
- `src/domain/recursive-language-model.ts`
- `src/application/run-recursive-prompt.ts`
- `src/application/agent-runner.ts`
- `src/application/ui-execution-runner.ts`
- `src/index.ts`

Steps:
1. Add optional runtime memory resolver/store context.
2. Inject memory packets into model messages for task/node calls where policy exists.
3. Append episodic entries after task completions and degraded memory events.
4. Keep memory failures visible but non-fatal unless required state is missing.

### Task 4: Tests and Verification

Files:
- `tests/memory-store.test.ts`
- `tests/recursive-language-model.test.ts`

Steps:
1. Test scope lifecycle, version conflict, unauthorized write rejection, and audit records.
2. Test bounded packet generation and metadata.
3. Test runtime memory packet injection and episodic append.
4. Run build and full tests.
