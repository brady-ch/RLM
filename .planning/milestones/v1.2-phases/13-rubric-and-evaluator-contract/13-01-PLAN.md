  <behavior>

    - Selection is deterministic from prompt/task text and does not call the model.
    - Selection metadata is written to `result.metadata.qualityLoop` and the execution graph node loop metadata.
  </behavior>
  <action>
    In `src/domain/recursive-language-model.ts`, import `QualityLoopRubricId`, `QualityLoopRubricSelection`, and `QualityLoopRubricCriterion`.
    Add a `QUALITY_LOOP_RUBRICS` constant keyed by the five rubric ids. Each definition must include a user-readable label and at least three criteria with stable ids.
    Add `selectQualityLoopRubric(prompt: string, task: TaskNode): QualityLoopRubricSelection`.
    The helper must choose:
    - `code_engineering` when prompt text includes code fences, file paths like `src/`, `.ts`, `.tsx`, `test`, `bug`, `fix`, `refactor`, `implement`, or TypeScript/Node terms.
    - `planning_architecture` when prompt text includes `plan`, `architecture`, `roadmap`, `design`, `tradeoff`, `system`, or `phase`.
    - `user_facing_writing` when prompt text includes `rewrite`, `copy`, `email`, `tone`, `blog`, `headline`, `announcement`, or `user documentation`.
    - `structured_artifact` when prompt text includes `json`, `yaml`, `schema`, `table`, `checklist`, `frontmatter`, `xml`, or `csv`.
    - `general_answer_quality` as fallback.
    Record matched signal strings and confidence as `Math.min(1, 0.45 + matchedSignals.length * 0.1)` for matches; fallback confidence must be `0.4`.
    In `runQualityLoop()`, set `metadata.rubric = selectQualityLoopRubric(task.prompt, task)` before the first `writeLoopMetadata(task.id, metadata)`.
  </action>
