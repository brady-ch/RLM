# Sketch 001: Workflow + Advanced Shell

## Design Question

Compare three shell approaches for the approved architecture: recommended workflow+dock, ultra-minimal canvas-only, and the Advanced hub takeover.

## How to View

```bash
open .planning/sketches/001-workflow-advanced-shell/index.html
# or xdg-open on Linux
```

## Variants

- **A: Canvas + node dock ★ Recommended** — Top bar, full canvas, 360px dock on node select (Edit/Run tabs)
- **B: Canvas only** — No dock; all node actions on cards (most minimal, crowded cards)
- **C: Advanced hub** — Full-screen Models/Plugins/Sessions/Memory/Settings with Back to workflow

## What to Look For

- Does the workflow view feel uncluttered compared to today's scrollable sidebar?
- Is the node dock the right amount of context without becoming a second sidebar?
- Does Advanced takeover clearly separate setup from authoring?
