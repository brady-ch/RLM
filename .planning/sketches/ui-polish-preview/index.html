Running the real RLM UI locally
Mockups above — static HTML on this preview server.

Live Rust-served UI (needs build + control server): 
npm run build:ui && RLM_UI_DIST=$PWD/ui/dist cargo run -p rlm-cli -- ui --port 5173
Vite dev (frontend only, API calls may fail without backend): 
npm run dev:ui

Preview server URL will appear in your terminal.
